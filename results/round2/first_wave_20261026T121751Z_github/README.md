# Operator Walshness 第二轮首批结果

本目录是 GitHub 精简发布版。全部标量结果、图表、运行配置、51 项单元测试记录和数据验收记录均保留；没有上传模型权重、原始 NPZ、缓存、失败尝试和完整实验压缩包。

- [实验报告](report.html)（下载后在浏览器打开；保留同目录下的图和表）
- [图表](figures/)、[全部标量结果](tables/)、[运行配置](config/)
- [机器可读汇总](summary.json)、[完整本地数据验收记录](acceptance.json)
- [代码与复现说明](../../../ROUND2_RUNBOOK.md)

完成范围：3,264 次首批 MLP 训练，576 次选定配置的 40,000 步训练；276 行空间关联结果；7,200 个随机基准样本及 5,000 个独立验证样本；87 个 QMC 物理参数点、1,416 个基底评估。原研究规格的全量网格与条件性 R5 未执行。

关键结果：n=12、β=1、宽度64、两层 tanh、40,000 步时，8个种子的平均平方相对 Frobenius 误差由原基底的 0.531 降至 Walsh 优化基底的 0.000248。当前实基底搜索预算内，87 个 QMC 参数点没有出现 Walsh 优化对平均符号的显著改善。具体限制和负结果见报告。

较大的表为 `.csv.gz`，可直接用 `pandas.read_csv(path)` 读取。验收脚本需要本地完整运行目录，不能直接对本精简目录运行。表格中的 `source_file` 列指向原始完整运行中的逐任务记录，其文件没有重复上传。
